# Docs as code with RepoPages

This space is written in Markdown in a Git repository and published here by RepoPages. Nobody edits these pages in Confluence: a change is a pull request, a review and a merge, and the page follows the merge within seconds.

Start with [Getting started](getting-started.md), then read [How the sync works](how-it-works.md). The guides cover [authoring pages](guides/authoring.md) and [diagrams](guides/diagrams.md).

Every page in this space carries a byline with the commit that wrote it. Click it to see the exact change in Git.
